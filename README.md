# MVP мультилендинга для мотосервиса

Этот репозиторий содержит прототип системы мультилендингов для мотосервиса. Цель клиента: получать низкочастотный поисковый трафик за счет большого числа посадочных страниц под конкретные комбинации услуги, типа техники, бренда, модели и географии.

Пример страницы:

```text
/landings/to-yamaha-r6-moskva/
```

Видимая страница должна выглядеть как обычный полезный лендинг сервиса, а не как демонстрация генератора. Служебные данные остаются внутри системы: `title`, `description`, `canonical`, `robots`, `sitemap.xml`, статусы индексации.

## Что уже реализовано

- Светлый адаптивный шаблон лендинга.
- Генератор HTML-страниц из JSON-данных.
- Несколько демо-страниц в папке `landings/`.
- Автоматическая генерация `sitemap.xml`.
- Поддержка статуса `index` / `noindex`.
- Разные H1, meta description, список работ, FAQ, блок брендов/моделей и форма обращения для разных страниц.
- Коммерческие блоки по структуре исходного сайта: услуги, популярные работы, бренды, запчасти, покраска, ателье, контакты, WhatsApp/Telegram.

## Структура проекта

```text
data/landings.json       данные посадочных страниц
scripts/generate.js      генератор HTML и sitemap.xml
styles.css               общая светлая дизайн-система
script.js                простые интерактивные элементы
index.html               главная демо-страница
landings/*/index.html    сгенерированные посадочные страницы
sitemap.xml              карта индексируемых страниц
docs/ROADMAP.md          план развития до production-системы
```

## Как запустить локально

```bash
npm run serve
```

После запуска:

```text
http://localhost:4173/index.html
```

## Как пересобрать страницы

После изменения `data/landings.json`:

```bash
npm run generate
```

Команда пересоздает:

- `index.html`;
- все страницы в `landings/`;
- `sitemap.xml`.

## Как добавить новую посадочную страницу

Добавьте объект в `data/landings.json`:

```json
{
  "slug": "zamena-cepi-yamaha-r6-moskva",
  "service": "Замена цепи",
  "vehicle": "мотоцикла",
  "brand": "Yamaha",
  "model": "R6",
  "location": "Москве",
  "intent": "ремонт",
  "status": "index",
  "priceFrom": "от 3 500 ₽",
  "lead": "Замена цепи и звезд Yamaha R6 с проверкой натяжения, износа и состояния задней звезды.",
  "works": ["осмотр цепи", "замена цепи", "замена звезд", "регулировка натяжения", "проверка тестовым проездом"],
  "faq": [
    ["Можно поставить свои запчасти?", "Да, если цепь и звезды подходят по спецификации."],
    ["Сколько занимает работа?", "Обычно от 1 часа после приемки техники."]
  ]
}
```

Затем выполните:

```bash
npm run generate
```

## Важное SEO-ограничение

Нельзя выпускать тысячи страниц, которые отличаются только H1 и парой слов. Это риск получить низкокачественные страницы или дорвейную структуру.

Для масштабирования каждая группа страниц должна получать полезные отличия:

- реальные подуслуги;
- модели и особенности бренда;
- частые неисправности;
- FAQ;
- цены или диапазоны;
- связанные услуги;
- фото/примеры работ;
- внутреннюю перелинковку.

Подробный план развития: [docs/ROADMAP.md](docs/ROADMAP.md).
